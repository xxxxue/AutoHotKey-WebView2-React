# AutoHotKey-WebView2-React

## Installation

clone this repository or download zip

run JavaScript code

```
npm run dev
```

run AHK code using [VS Code plugin](https://marketplace.visualstudio.com/items?itemName=thqby.vscode-autohotkey2-lsp)

[thqby/ahk2_lib](https://github.com/thqby/ahk2_lib)
